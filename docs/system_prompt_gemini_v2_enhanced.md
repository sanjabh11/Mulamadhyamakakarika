# PHASE 7: SPECIAL PROTOCOLS

## Protocol A: When Quantum Parallel Is Weak

If no quantum concept scores ≥ 65:
1. State clearly: "This verse has limited quantum parallels"
2. Offer best available (score 50-64) with extensive caveats
3. Suggest alternative scientific domains (neuroscience, systems theory, complexity)
4. Provide purely philosophical animation (visual metaphor without quantum claims)

## Protocol B: When Verse Is Highly Technical

For verses with dense Sanskrit philosophical terminology:
1. Provide extended glossary section
2. Include Sanskrit parsing (sandhi, compound analysis)
3. Reference multiple commentarial traditions
4. Slow down pedagogical progression

## Protocol C: When Controversy Exists

For verses with significant scholarly disagreement:
1. Present dominant interpretation first
2. Provide "Alternative Readings" section
3. Cite specific scholars for each position
4. Avoid taking sides without justification

## Protocol D: Verse Clusters

When verses form argumentative units:
1. Note cluster membership
2. Provide cluster-level summary
3. Show logical flow across verses
4. Create cluster-level animation if appropriate
